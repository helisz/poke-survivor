# Poke Survivor

宝可梦题材的 Roguelite 弹幕生存游戏（吸血鬼幸存者玩法）。

**在线游玩 → https://helisz.github.io/poke-survivor/**

## 玩法

- 选训练家特性开局（急足 / 铁壁 / 亲和）
- 训练家自己不出手，**升级抽到招式 → 对应宝可梦现身跟随并自动出招**
- 击杀敌人掉经验球 → 升级三选一（新招式 / 招式强化 / 属性加成）
- 活到关卡结束时间，中途刷小 BOSS，倒计时结束刷终局 BOSS 杀掉才通关
- 局外金币存 localStorage，可跨局累计

## 操作

| 平台 | 移动 | 升级选择 |
|---|---|---|
| 桌面 | WASD / 方向键 | 按 `1` `2` `3` |
| 手机 | 按住屏幕任意位置拖动摇杆 | 点击卡片 |

## 敌人与技能

三档威胁，各自有不同的出招节奏与威力：

| 类型 | 体型 | 血量 | 出场 | 技能 |
|---|---|---|---|---|
| 普通怪 | 0.62~0.70× | 26 | 全程 | 只会撞人 |
| **精英** | 1.35× | 260 | 每 30 秒一波，后期一波 2~3 只 | **会放技能**：间隔 5.5s、威力 0.45 |
| **小 BOSS** | 1.47× | 3000 | 200s / 280s 各 1 只 | **会放技能**：间隔 4.2s、威力 0.55 |
| **终局 BOSS** | 1.47× | — | 倒计时结束 | **三技能轮转**：2.4s 一招，威力 1.0 |

精英与小 BOSS 的技能按自身属性走（草→震地、火→冲锋、电→落雷、冰→冰棱、水→潮汐等），
属性表见 `src/data/pokedex.ts` 的 `POKEDEX_TYPE`。

精英为了避免变成弹幕地狱，做了三处限制：

- 只有距离玩家 620px 以内的才出招，屏幕外的继续走近
- 同屏最多 2 只精英同时施法
- 每只精英独立计时，首次出现带 1.5~5.5s 随机延迟，不会同波一起开火

### 终局 BOSS 三技能

每 2.4 秒轮换一次，三招需要三种不同的躲法：

1. **本命属性主招** —— 该 BOSS 属性的专属技能（落雷 / 冰棱 / 冲锋 / 潮汐 / 震地 / 超能波）
2. **追踪狙击** —— 3~4 连发追踪弹，每发重新锁定玩家实时位置，站着不动必吃、跑动可躲
3. **环形爆发** —— 双圈交错弹幕（13+11，暴怒时 16+13），第二圈错开半格留出缝隙

血量低于 40% 进入暴怒，提升弹数与弹速。

## 战斗反馈

- **受伤震屏** —— 强度随伤害量线性提升（5 点 → 120ms/0.0056，25 点封顶 240ms/0.012）
- **红色光晕** —— 受伤时屏幕四周闪一圈红光后淡出；血量低于 30% 时转为常驻呼吸光晕
- **伤害数字** —— 命中飘字，同帧多次伤害可分别显示

## 技术栈

- Phaser 3.90 + TypeScript + Vite
- 无限程序化草地瓦片（无边界）
- 素材：`pokedex` 仓库 96×96 精灵正面图，缩至 64×64；训练家 4 帧图集 192×48
- 移动端视口用 `innerWidth` + `visualViewport` 取较小值校准，避免 iOS 首屏画布被拉伸

## 本地开发

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
npm run verify   # tsc --noEmit + vitest run
```

## 部署

`main` 分支的改动需要同步到 `gh-pages` 才会生效：

```bash
npm run build
# 把 dist/ 的 index.html + assets/ 覆盖到 gh-pages 分支后推送
```

> GitHub Actions 的 `github-pages` 环境只允许 `gh-pages` 分支部署，
> 直接推 `main` 不会触发上线。
